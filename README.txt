PREMKUMAR PORTFOLIO
===================

Files:
- index.html   -> main portfolio page
- style.css    -> complete responsive design
- script.js    -> typing effect, scroll navigation, counters, filters, theme toggle, menu and contact form
- professional.jpeg -> ADD YOUR PROFILE PHOTO HERE (same folder)
- resume.pdf -> OPTIONAL: add your resume with this exact filename for the Download Resume button

HOW TO RUN
----------
1. Put your profile photo in this folder and name it: professional.jpeg
2. Optional: put your resume in this folder and name it: resume.pdf
3. Open index.html in Chrome.

IMPORTANT
---------
The portfolio is designed for desktop first: text/content stays on the LEFT and the profile visual stays on the RIGHT.
On mobile, the layout becomes one column automatically.

The contact form is currently frontend-only. Connect it to your Spring Boot API when ready.
